# Défense du chantier, rondes du guerrier, nuits dehors. Fichier UTF-8.
#
# FORMAT : exactement celui de vie.txt, remarques.txt et relations.txt (même lecteur possible : Vie.lire).
# Les lignes vides et les lignes qui commencent par # sont ignorées.
#
#   [cle]
#   réplique pour tous
#   colerique: réplique réservée aux colériques
#
# - « [cle] » ouvre une section. Clé en minuscules, sans accent ni espace (lettres, chiffres et « _ »),
#   unique dans ce fichier ET différente de toutes les clés de vie.txt, remarques.txt et relations.txt.
# - Une réplique par ligne, courte (bulle en jeu, 90 caractères au plus). Préfixe facultatif « temperament: »
#   (calme:, peureux:, fourbe:, colerique: ; aucun autre). Chaque section a au moins huit répliques sans préfixe
#   et au moins deux par tempérament.
# - Tirage proposé (comme vie.txt) : une fois sur deux une réplique du tempérament du PNJ, sinon une commune.
# - Les caractères sont les quatre tempéraments du mod : calme (posé, digne), peureux (timide),
#   fourbe (rusé, rancunier), colerique (soupe au lait, mais vite apaisé).
#
# VARIABLES (seulement celles-ci)
#   {chef}   nom du chef de la colonie (partout)
#   {nom}    prénom du guerrier prévenu, dans creeper_alerte ; prénom du collègue envoyé à sa place, dans
#            monstre_pousse. Nulle part ailleurs.
# Les répliques avec {nom} ne sortent que si la valeur est connue ; creeper_alerte et monstre_pousse gardent
# au moins huit répliques communes sans {nom}.
#
# ACCORDS : comme vie.txt, aucun accord de genre sur celui qui parle, sur {nom} ni sur le chef.
# Aucun fait inventé : monstre_vu, guerrier_monstre_tue et les sections monstre_ ne nomment pas l'espèce du
# monstre (le code ne la donne pas) ; seules les sections creeper_, monstre_creeper_recule et guerrier_alerte_ok
# (réponse à creeper_alerte) parlent du creeper.
#
# CLÉS
#   creeper_fuite          l'ouvrier voit un creeper près du chantier et s'éloigne en criant
#   creeper_alerte         il prévient le guerrier ({nom}) qu'un creeper est là
#   guerrier_alerte_ok     le guerrier répond qu'il s'en occupe
#   guerrier_monstre_tue   le guerrier vient de tuer un monstre
#   ronde_nuit             le guerrier part faire sa ronde de nuit autour du poste
#   nuit_camp              un ouvrier loin de la colonie voit la nuit tomber et décide de camper
#   nuit_cache             il se cache, se mure dans son abri pour la nuit
#   matin_reprise          au matin, il sort de son abri et reprend la route ou le travail
#   monstre_vu             un ouvrier signale un monstre près du poste
#   lettre_nuit_dehors     corps d'une lettre au chef (une ligne, deux ou trois phrases) : « je passe la nuit
#                          dehors, je rentre demain ». Le code ajoute la salutation, la formule et la signature
#                          (Messages.lettre) ; si le chef est tout près, le même texte est dit en bulle.
#   monstre_charge         il fonce sur un monstre pour se battre avec ce qu'il a en main (surtout colérique)
#   monstre_riposte        attaqué (ou un collègue l'est juste à côté), il se défend (surtout calme)
#   monstre_panique        il fuit un monstre en criant (surtout peureux)
#   monstre_eclipse        il s'éclipse en douce, sans prévenir personne (surtout fourbe)
#   monstre_pousse         il envoie un collègue ({nom}) se battre à sa place (surtout fourbe)
#   monstre_abattu         un ouvrier (pas un guerrier) vient de tuer un monstre : fier ou soulagé
#   monstre_creeper_recule il voulait se battre, voit que c'est un creeper et recule quand même (orgueil blessé)
# ------------------------------------------------------------
