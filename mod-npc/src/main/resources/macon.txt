# Le maçon : il bâtit un plan (schéma) avec les matériaux du dépôt de son poste (lot 10). Fichier UTF-8.
#
# FORMAT : exactement celui de vie.txt, remarques.txt, relations.txt et defense.txt (même lecteur possible : Vie.lire).
# Les lignes vides et les lignes qui commencent par # sont ignorées.
#
#   [cle]
#   réplique pour tous
#   colerique: réplique réservée aux colériques
#
# - « [cle] » ouvre une section. Clé en minuscules, sans accent ni espace (lettres, chiffres et « _ »),
#   unique dans ce fichier ET différente de toutes les clés de vie.txt, remarques.txt, relations.txt et defense.txt
#   (préfixe macon_).
# - Une réplique par ligne, courte (bulle en jeu, 90 caractères au plus, variables remplies). Préfixe facultatif
#   « temperament: » (calme:, peureux:, fourbe:, colerique: ; aucun autre). Chaque section a au moins huit répliques
#   sans préfixe et au moins deux par tempérament.
# - Tirage proposé (comme vie.txt) : une fois sur deux une réplique du tempérament du PNJ, sinon une commune.
# - Les caractères sont les quatre tempéraments du mod : calme (posé, digne), peureux (timide),
#   fourbe (rusé, rancunier), colerique (soupe au lait, mais vite apaisé).
#
# VARIABLES (seulement celles-ci)
#   {chef}   nom du chef de la colonie (partout)
#   {plan}   nom de l'ouvrage, tel que le donne le plan (« cabane »), dans macon_construire_ok et macon_fini seulement ;
#            toujours écrit entre guillemets « {plan} », comme dans les lettres
#   {objet}  le matériau qui manque, tel qu'on le dit (« des planches de chêne »), dans macon_manque seulement ;
#            toujours après deux-points, pour ne pas dépendre de l'article
# Les répliques avec une variable ne sortent que si la valeur est connue ; chaque section garde au moins huit
# répliques communes sans {plan} ni {objet}.
#
# ACCORDS : comme vie.txt, aucun accord de genre sur celui qui parle, sur le chef ni sur l'ouvrage.
# Aucun fait inventé : on ne nomme ni le nombre de pierres, ni les blocs sautés, ni l'endroit exact ; le code les
# donne dans les lettres (Messages : materiau_manque, chantier_fini, chantier_gene, schema_perdu), pas ici.
#
# CLÉS
#   macon_construire_ok    le chef lui demande de bâtir un ouvrage ({plan}) à un endroit : il accepte
#   macon_pause            le chef lui dit d'arrêter un moment : il pose ses outils, le chantier attend
#   macon_reprise          le chef lui dit de reprendre le chantier en attente
#   macon_abandon          le chef abandonne le chantier : ce qui est bâti reste bâti
#   macon_sans_chantier    on lui parle de chantier (pause, reprise, abandon, travail) mais il n'en a aucun
#   macon_fini             l'ouvrage ({plan}) est bâti
#   macon_manque           il lui manque un matériau ({objet}) au dépôt : le chantier attend
#   macon_approvisionne    il va prendre des matériaux au dépôt du poste
#   macon_plan_create      le chef lui a donné un plan de Create déjà placé : il le bâtit là où il est placé
#   macon_plan_illisible   ce plan de Create, il n'arrive pas à le lire (il faut l'envoyer à la table d'abord)
#   macon_plan_loin        le chantier (endroit montré ou plan placé) est trop loin du poste : il refuse
# ------------------------------------------------------------
