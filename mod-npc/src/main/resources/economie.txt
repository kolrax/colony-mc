#   [cle]

#   colerique: réplique réservée aux colériques
# Préfixes possibles : calme:, peureux:, fourbe:, colerique:. Une réplique par ligne, 90 caractères au plus.
# La monnaie : les pièces de la colonie (pièces, sous, écus). Jamais de banque.
#
# VARIABLES
#   {chef}   nom du chef (partout)
#   {nom}    l'autre PNJ : le vendeur, l'acheteur ou le boutiquier
#   {objet}  ce qui s'achète, tel qu'on le dit, avec son article (« du pain », « une hache »)
#   {prix}   nombre de pièces, en chiffres ; les répliques disent « {prix} pièces » : prix de 2 au moins,
#            ou le code remplace « 1 pièces » par « 1 pièce »
#
# CLÉS
#   achat_demande        il demande à acheter {objet} à {nom}
#   achat_accepte        le vendeur accepte de vendre {objet} pour {prix} pièces
#   achat_marchande      il trouve le prix ({prix}) trop cher et marchande
#   achat_refuse_cher    trop cher : il renonce
#   achat_pas_assez      il n'a pas assez de pièces pour payer {prix}
#   vente_propose        un vendeur vante sa marchandise ({objet})
#   vente_faite          le vendeur est content après la vente (à {nom})
#   vente_rupture        le vendeur n'a plus rien à vendre
#   boutique_ouverte     le boutiquier ouvre sa boutique
#   boutique_fermee      la boutique est fermée (le boutiquier, ou un client devant la porte de {nom})
#   paie_depensee        remarque : il a déjà dépensé toute sa paie
#   paie_economise       il met des pièces de côté (surtout calmes et fourbes)
#   prix_monte           remarque : les prix montent
#   riche_fier           il a la bourse pleine et s'en vante
#   pauvre_plainte       il a la bourse vide et s'en plaint
#   chef_achat_info      réponse au chef qui demande ce qu'il a acheté ({objet}, {nom}, {prix})
#   lettre_boutique_vide ligne courte d'une lettre : la boutique de {nom} n'a plus rien
#   boutique_ordre_ouvrir  le chef lui dit de tenir la boutique : il accepte
#   boutique_ordre_fermer  le chef lui dit de la fermer
#   boutique_ordre_prix    le chef fixe un prix : {objet} (son nom, sans article), {prix} pièces l'unité
#   boutique_ordre_exclu   le chef lui dit de ne pas vendre {objet} (son nom, sans article)
#   boutique_ordre_permis  {objet} est de nouveau à vendre (son nom, sans article)
#   boutique_ordre_lot     le chef donne le prix d'un lot (« 20 torches pour 2 pièces ») : il demande celui d'une seule
#   boutique_inconnu       le chef parle d'une marchandise qu'il ne connaît pas : {objet}, le mot dit
#   vente_etal             il dit ce qu'il vend : {objet} est la liste (« pain à 1 pièce et steak à 3 pièces »)
#   vente_absent           le client demande ce qu'il ne vend pas
#   vente_conclue          il vend {objet} (« 2 pains ») au client {nom} pour {prix} pièces en tout
#   vente_pas_assez        le client {nom} n'a pas les {prix} pièces
#   vente_sans_monnaie     la caisse ne peut pas rendre la monnaie : il faut le compte juste
