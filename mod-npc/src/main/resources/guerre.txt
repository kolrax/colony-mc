# La guerre entre colonies : déclaration, armée, assaut, défense, paix (cahier : guerre simple). Fichier UTF-8.

# FORMAT : exactement celui de vie.txt, defense.txt et chef.txt (même lecteur : Vie.lire).
#   [cle]
#   réplique pour tous
#   colerique: réplique réservée aux colériques
# Préfixes possibles : calme:, peureux:, fourbe:, colerique:. Une réplique par ligne, 90 caractères au plus.
#
# RÈGLE : un PNJ ne frappe un joueur que sur ordre de son chef, en guerre. Hors guerre, il refuse.
#
# VARIABLES
#   {chef}     nom de son chef (partout)
#   {ennemi}   nom du chef ennemi (partout)
#   {nom}      prénom d'un collègue (guerre_levee, guerre_renfort_propose, guerre_blesse)
#              ou d'un ennemi (guerre_ennemi_vu)
#
# CLÉS
#   guerre_declaree          le chef déclare la guerre à {ennemi} : réaction de l'ouvrier
#   guerre_recue             on apprend que {ennemi} nous a déclaré la guerre
#   guerre_levee             le guerrier rejoint l'armée
#   guerre_renfort_propose   un fermier ou un autre civil propose de venir en renfort
#   guerre_renfort_refuse    un civil peureux refuse d'y aller
#   guerre_en_marche         en route vers la colonie ennemie
#   guerre_assaut            au moment d'attaquer
#   guerre_casse             il casse un mur ou une porte ennemis
#   guerre_brule             il met le feu
#   guerre_vol               il emporte un butin
#   guerre_ennemi_vu         il voit un ouvrier ou un guerrier ennemi près de chez lui
#   guerre_defense           il défend sa colonie contre l'attaque
#   guerre_blesse            blessé en guerre
#   guerre_retraite          le chef ordonne la retraite
#   guerre_victoire          la guerre est gagnée
#   guerre_defaite           la guerre est perdue
#   guerre_paix              la paix est signée avec {ennemi}
#   guerre_refus_hors_guerre on lui demande d'attaquer un joueur sans guerre ni ordre clair : il refuse poliment
#   lettre_guerre_attaque    ligne courte pour une lettre au chef : la colonie est attaquée par les gens de {ennemi}
