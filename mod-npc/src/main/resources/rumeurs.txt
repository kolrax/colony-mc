# Les rumeurs et l'espionnage : ce que les ouvriers savent des autres colonies (cahier 7.5 et 7.6). Fichier UTF-8.
#
# FORMAT : exactement celui de vie.txt (même lecteur : Vie.lire).
#   [cle]
#   réplique pour tous
#   colerique: réplique réservée aux colériques
# Préfixes possibles : calme:, peureux:, fourbe:, colerique:. Une réplique par ligne, 90 caractères au plus.
# Chaque section a au moins quatre répliques pour tous.
#
# QUI PARLE, À QUI
# - L'ouvrier parle à son chef (tutoiement, « chef » ou {chef}) ; à un étranger, il le tutoie aussi.
# - Aucun fait inventé : l'ouvrier ne dit que ce que les variables lui donnent. Quand le code ajoute
#   l'information après la réplique (rumeur_entendu_intro, rumeur_trahit_chef, espion_retour),
#   la réplique finit par « : » et n'annonce rien d'autre.
# - Pas d'accord de genre sur celui qui parle (« on m'a repéré » plutôt que « j'ai été repéré »).
#
# VARIABLES
#   {chef}      nom du chef de l'ouvrier (partout)
#   {nom}       le chef d'une autre colonie, celui dont on parle
#   {nombre}    nombre d'ouvriers vus (écrit « {nombre} ouvriers » : « 1 ouvriers » est à corriger par le code)
#   {metiers}   les métiers vus, déjà en texte : « deux mineurs et un bûcheron »
#   {jours}     quand, déjà en texte : « hier », « il y a 3 jours » (en tête de phrase : majuscule par le code)
#   {direction} où, déjà en texte avec sa préposition : « au nord », « au sud-est »
#   {distance}  à quelle distance, nombre et unité : « 300 pas »
#   {autre}     le chef d'une autre colonie, en guerre contre {nom}
#   {de}        prénom de l'ouvrier qui a raconté la nouvelle
#   {a}, {b}    rumeur_passe : {a} dit la bulle à {b} (seul {b} est nommé dans le texte)
#
# CLÉS
#   rumeur_vu_nombre        il a vu {nombre} ouvriers chez {nom}, {jours}
#   rumeur_vu_metiers       il a vu les métiers de chez {nom}, {jours}
#   rumeur_vu_poste         il sait où est le poste de {nom}
#   rumeur_guerre           {nom} est en guerre contre {autre}
#   rumeur_mort             un ouvrier de {nom} est mort
#   rumeur_naissance        un enfant est né chez {nom}
#   rumeur_debauche         {nom} débauche les ouvriers des autres
#   rumeur_boutique         {nom} tient boutique, vend et achète
#   rumeur_entendu_intro    avant une nouvelle de seconde main : {de} la lui a dite
#   rumeur_rien             il ne sait rien sur {nom}
#   rumeur_rien_du_tout     il n'a aucune nouvelle de personne
#   rumeur_tais_chef        un étranger lui demande des nouvelles de {chef} : il se tait
#   rumeur_trahit_chef      fourbe ou mécontent : il lâche quand même une info sur {chef}, à voix basse
#   espion_part             il part espionner la colonie de {nom}
#   espion_inconnu          il ne sait pas où est la colonie de {nom}
#   espion_retour           il revient de chez {nom} ; ce qu'il a vu suit
#   espion_repere           un ouvrier de {nom} l'a repéré
#   espion_refus_enfant     un enfant à qui l'on demande d'espionner
#   rumeur_passe            bulle : il passe une nouvelle sur {nom} à un collègue

{nom} a {nombre} ouvriers. Je les ai vus de mes yeux, {jours}.
{jours}, chez {nom}, j'ai vu {nombre} ouvriers à l'ouvrage.
{nombre} ouvriers chez {nom}, chef. Vus {jours}.
calme: J'ai bien compté, chef : {nombre} ouvriers chez {nom}, {jours}.
peureux: {jours}, chez {nom}… {nombre} ouvriers. Je n'ai pas traîné.
fourbe: {jours}, j'ai jeté un œil chez {nom}. {nombre} ouvriers, pas un de plus.
colerique: {nom} ? {nombre} ouvriers, vus {jours}. Rien de quoi trembler.

[rumeur_debauche]

fourbe: {nom} paie bien, à ce qu'on dit. Je dis ça, je ne dis rien.

[rumeur_boutique]
