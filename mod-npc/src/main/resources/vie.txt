# Répliques de la vie des PNJ : corps, santé, moral, deuil, réactions (lot 5). Fichier UTF-8.
#
# FORMAT
# Les lignes vides et les lignes qui commencent par # sont ignorées.
#
#   [cle]
#   réplique pour tous
#   réplique pour tous
#   colerique: réplique réservée aux colériques
#   peureux: réplique réservée aux peureux
#
# - « [cle] » ouvre une section : une situation. La clé est courte, en minuscules, sans accent ni espace
#   (lettres, chiffres et « _ »). Chaque clé n'apparaît qu'une fois dans le fichier.
# - Chaque ligne qui suit est une réplique, jusqu'à la section suivante. Une réplique tient sur une ligne.
# - Préfixe facultatif « temperament: » en tout début de ligne : la réplique n'est dite que par un PNJ de ce
#   tempérament. Préfixes permis (aucun autre) : calme:, peureux:, fourbe:, colerique:
#   Un espace suit les deux-points. Aucune réplique sans préfixe ne commence par l'un de ces mots suivi de « : ».
# - Les répliques sans préfixe sont pour tout le monde. Chaque section en a au moins quatre, pour qu'aucun
#   tempérament ne reste muet. Proposition de tirage (comme Messages.java) : une fois sur deux, une réplique
#   du tempérament du PNJ s'il en a ; sinon une réplique commune.
#
# VARIABLES (remplacées par le code ; seulement dans les sections indiquées)
#   {chef}   nom du chef de la colonie (partout)
#   {nom}    prénom de l'autre PNJ en jeu : celui qui soigne (soigne), qui a pris le lit (lit_vole),
#            le blessé à terre (blesse_vu), celui que le guérisseur a relevé ou pansé (guerisseur_soigne)
#   {objet}  l'objet en jeu, tel qu'on le dit (« du pain », « une pioche ») : vol, sabotage_avoue, cadeau
#   {mort}   prénom du PNJ mort : ami_mort, deuil_annonce, deuil_tristesse, enterrement_discours,
#            enterrement_apaisement
#
# QUI PARLE, À QUI
# - Celui qui parle est le PNJ concerné. Il parle au chef (tutoiement, comme dans Messages.java) ou à voix
#   haute pour les autres, en bulle. Les textes évitent les accords de genre sur celui qui parle, sur le chef
#   et sur le mort (« j'ai sommeil » plutôt que « je suis fatigué » ; « {mort} nous a quittés »).
# - Aucun fait inventé : pas de monstre, de lieu ni de jour précis qui ne serait pas arrivé.
#
# SECTIONS
#   Corps :      faim_legere, faim_forte, fatigue, sans_lit, lit_vole
#   Santé :      blessure_legere, blessure_grave, a_terre, releve, soigne, blesse_vu, guerisseur_soigne
#   Loisirs :    envie_pause
#   Moral bas :  plainte_douce, plainte_forte, menace_greve, greve, menace_demission, demission, fuite_nuit,
#                vol, sabotage_avoue, avertissement_1, avertissement_2, avertissement_3, revolte
#   Moral haut : content, fier_colonie
#   Causes :     paie_retard, repas_pareils, repas_varies, danger, chef_crie, chef_poli, meteo_mauvaise,
#                meteo_belle, ami_mort
#   Deuil :      deuil_annonce, deuil_tristesse, enterrement_discours, enterrement_apaisement
#   Réactions :  insulte, coup, impaye, diamant_avoue, diamant_nie, cadeau
