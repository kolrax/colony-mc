# Répertoire des actions des ouvriers (mod colonie_pnj).
#
# Une action par ligne :   id | qui | ce qu'elle fait | programme | ce qu'on dit pour la demander | réponses sans IA (facultatif)
#   qui        : « tous », ou des métiers séparés par des virgules (mineur, bucheron, guerrier)
#   ce qu'elle fait : quelques mots, montrés à l'IA et dans le panneau
#   programme  : le comportement qui la joue, son argument, puis des réglages clé=valeur (voir Consignes.java) :
#                geste <geste> [duree=4s|2m|tenu] [regard=chef|devant|ciel|sol|la|cible|autour|dos|aucun] [son=…] [rythme=ticks]
#                      [part=…] [objet=…] [saut] [tourne] [spontane]
#                aller <lieu> [puis=<id>] [tenu] [vite]      suivre <qui>        regarder <quoi> [duree=…]
#                son <son> [fois=n] [geste=…] [part=…]          musique <instrument> [duree=…]
#                donner <objet> [a=cible]   jeter <objet>   prendre <objet> [n=…]   tenir <objet>   ranger   deposer   manger   dormir
#                utiliser <bloc>   combat <mode>   travail <mode> [n=…]   info <sujet>   parler <genre> [geste=…] [part=…]
#                silence [duree=…]   parole   vitesse <rapide|lent|normal>   formation <rang|file|cercle|derriere>   arret   annuler
#                [remplace=…] : ordres de base ou missions que la phrase ne veut pas dire quand cette action est demandée
#   ce qu'on dit : des formules séparées par « ; » (accents et ponctuation ignorés, les verbes se reconnaissent conjugués)
# Les lignes « ## Titre » ouvrent une catégorie.
