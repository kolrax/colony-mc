# Conversations entre PNJ, sans IA (lot 7). Fichier UTF-8.
#
# FORMAT
# Un bloc par conversation. Les lignes vides et les lignes qui commencent par # sont ignorées.
#
#   = sujet | conditions
#   A | première réplique (dite par A)
#   B | réponse (dite par B)
#   A | ...
#
# - La ligne « = » ouvre un bloc. « sujet » est un mot court (travail, meteo, paie, chef…), sans espace.
# - « conditions » : liste séparée par des virgules. Toutes doivent être vraies (ET). Vide = toujours possible.
#   La barre « | » reste obligatoire même si la liste est vide : « = travail | ».
# - Puis 2 à 6 répliques, une par ligne : « A | texte » ou « B | texte ». A parle toujours en premier,
#   et les répliques alternent strictement A, B, A, B…
# - A et B sont deux PNJ de la même colonie, assez proches l'un de l'autre.
#
# VARIABLES (remplacées par le code)
#   {a}         prénom de A
#   {b}         prénom de B
#   {chef}      nom du chef de la colonie
#   {metier_a}  métier de A, tel qu'on le dit (« bûcheron », « mineur »…)
#   {metier_b}  métier de B
#
# Les textes évitent les accords de genre sur A et B (les PNJ sont des hommes et des femmes) :
# « j'ai sommeil » plutôt que « je suis fatigué ».
#
# CONDITIONS DÉCLARÉES (aucune autre n'est permise)
#   Moment :     matin, soir, nuit
#   Temps :      pluie, orage, neige, beau_temps
#   Paie :       paie_recue (payé dans la journée), paie_en_retard (au moins un jour de retard)
#   Corps :      faim, fatigue
#   Moral :      moral_bas, moral_haut
#   Événement :  apres_danger (un monstre ou un danger vient d'être écarté près d'eux)
#   Métiers :    metier_a=X, metier_b=X, meme_metier (A et B ont le même métier)
#                X parmi : mineur, bucheron, guerrier, fermier, eleveur, pecheur, chasseur,
#                          cuisinier, boulanger, transporteur, guerisseur, macon
#   Caractère :  temperament_a=X, temperament_b=X
#                X parmi : calme, peureux, fourbe, colerique
#
# SUJETS UTILISÉS
#   travail, meteo, nuit, paie, nourriture, fatigue, chef, colonie, industrie, ragot, souvenir,
#   humour, amitie, chamaillerie, danger, moral
