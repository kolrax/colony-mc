# Carte du code du mod `colonie_pnj`

Mise à jour : 11/10/2026, mod 0.8.0. 42 classes, environ 15 000 lignes.
But : ouvrir seulement les fichiers utiles. Chaque ligne donne le rôle, la taille (en lignes), les classes liées et les pièges.


## Refonte 1.0.0 (17/10) : à lire d'abord
Les classes retirées (IA, ReponsesIA, ReglagesIA, DepensesIA, Voix, VoixSvc, Audio, Incompris, Adressage, Conversations, Causeries, Souvenirs, Relations, Liens, Famille, Ages, Rumeurs, Espions, Debauche, Achats, Humeur, Moral, Deuil, Remarques, Bravoure, Corbeau) n'existent plus : ignore leurs lignes plus bas (historique : étiquette git `v1-finale`).
Nouvelles classes :
- `Missions` : `donner(p, t, id, repetition, nombre, horaires, lieu)` et `action(p, t, action, données)` (boutons de la fiche), droits (`autorise`), réponses courtes. Même entrée pour l'écran et le joueur fantôme. `valider` et « rentrer » appellent `Travailleur.majPoste()` (le poste du chef relu tout de suite, aussi à l'embauche ; sinon une fois par seconde dans `tickCourrier`).
- `Statut` (pur) : le texte unique au-dessus de la tête (en cours, ⚠ bloqué avec solution, en attente, hors horaires) ; constantes de blocage par métier en fin de fichier (dont `SANS_REMEDE`, le guérisseur). `Travailleur.STATUT`, `majStatut` (5 s), `bloquer`/`debloquer`, `lieuTravail`, `lieuImpose`/`travailleIci`.
- `Lieux` (jeu) et `LieuxRegles` (pur) : colonie, tampon, blocs naturels/construits, `peutCasser`, puits du mineur, arbres permis, structures.
- `BarreCommandes` : touche B (client), `Recherche` (pure), `executer(p, t, idAction)` (serveur), paquet `Reseau.Barre`.
- `Livret` : `livret.txt` → livre écrit, donné une fois avec le premier poste.
- `Fantome` : commande `/fantome` (dev ou `reglages.json` `fantome: true`), rapport JSON ; `tools/fantome.py`, scénarios dans `mod-npc/fantome/` Plan E6 : `Fantome.Survie` (pur Java, testé dans `FantomeTest`) note chaque mise à terre, relèvement seul et mort des ouvriers du fantôme avec sa cause (`Survie.cause`), l'heure et le lieu, et additionne les coups par cause ; crochets `Fantome.aTerre`/`mort`/`coup` dans `Travailleur.die`/`hurt`, `releveSeul` dans `Blessures.seRelever` ; rapport : `blessures`, `releves_seuls`, `morts`, `resume.survie`. Cible « mineur2 » = le 2e mineur embauché. Chiffres de survie au fichier de réglages : `vie_base`, `vie_par_etoile`, `a_terre_minutes` (recopié dans `Gravite.minutesATerre`), `releve_vie`, `blessure_jours_par_cran` (`Gravite.joursParCran`), `soin_lent_secondes`, avec `releve_seul_*`, `fuite_*`, `regen_*`.
- `Paroles` (bulles, heure) et `Essais` (outils de GameTests repris de l'ancien TestsIA ; `Essais.choisir` : `COLONIE_TESTS=enRang,sortDeLaLave COLONIE_FOIS=10 ./gradlew runGameTestServer` ne lance que ces tests, chacun N fois dans des lots successifs. Les copies d'un test qui travaille loin de sa structure, dans un coin du monde plat (`TestsJeu.sol`), se gênent entre elles : pour ceux-là, plusieurs lancements avec `COLONIE_FOIS=1`).
- Tests : `TestsMission`, `TestsPoste`, `TestsLieux`, `TestsMetiersMission`, `TestsBarre`, `TestsGuerre` (refait) ; JUnit `StatutTest`, `StatutMetiersTest`, `LieuxTest`, `BarreCommandesTest`, `LivretTest`, `FantomeTest`, `BoiteTest` (journal).
- Changés de rôle : `Courrier.ecrire` écrit une ligne au journal du poste ; `Boite` = règles du journal ; `Client.EcranPoste` = 5 onglets ; `Client.EcranOuvrier` = fiche ; `Guerre`/`Armee` = guerre simple (declarer, paix, Rang, Repli) ; `Obeissance` = jauge de satisfaction unique.

## Où sont les choses
- Code : `mod-npc/src/main/java/fr/lacolonie/pnj/` (36 classes, tests en jeu compris). Tests JUnit : `mod-npc/src/test/java/fr/lacolonie/pnj/` (6 classes).
- Ressources : `mod-npc/src/main/resources/`
  - `assets/colonie_pnj/` : bloc bureau (blockstates, modèles, textures `bureau_cote/dessus.png`), texture du corbeau, langues `fr_fr.json` / `en_us.json` ;
  - `data/colonie_pnj/` : recette et butin du bureau, structures de test `structure/vide.nbt` et `grand.nbt` ; `data/minecraft/tags/block/mineable/axe.json` ;
  - `repertoire.txt` (les actions demandables, une par ligne), `paroles.txt` (phrases sans IA), `conversations.txt` (237 conversations entre PNJ, sans IA, format et conditions en tête du fichier), `adressage.json` (poids appris : à qui le chef parle) ;
  - `web/index.html` : le panneau d'admin servi par le serveur Minecraft.
- `mod-npc/entrainement/` : exemples annotés et scripts Python de l'adressage. `mod-npc/outils/` : scripts qui dessinent les textures du bureau et du corbeau.
- Version : `mod-npc/gradle.properties` (`mod_version`). Tâches dans `mod-npc/build.gradle` (`runGameTestServer`, `runPhotos`, `entrainer`).

## Construire et tester
```bash
cd mod-npc
./gradlew build                                  # compile + 141 tests JUnit (lot 4, bûcheron : + 4 BucheronTest ; guerrier : + 2 GuerrierTest ; outils : + 2 OutilsTest ; fermier : + 4 FermierTest ; éleveur : + 4 EleveurTest, 164 en tout ; lot 5, guérisseur : + 6 SoinsTest ; lot 6, pêcheur : + 6 PecheTest ; cuisinier : + 4 CuisineTest)
rm -rf run/world && ./gradlew runGameTestServer  # 196 tests en jeu (lot 4 : + 9 TestsMineur, + 10 TestsBucheron, + 13 TestsGuerrier, + 7 TestsOutils ; lot 6 : + 8 TestsFermier, + 6 TestsEleveur ; lot 5 : + 5 TestsGuerisseur ; lot 6 : + 6 TestsPecheur, + 6 TestsCuisinier ; détail 0.9.4 : 48 TestsJeu, 22 TestsMorts, 19 TestsIA, 19 TestsRepertoire, 15 TestsOrdres, 13 TestsDeblocage, 12 TestsMessages, 7 TestsCharge)
./gradlew entrainer --args="code"                # réentraîne l'adressage (adressage.json)
./gradlew runPhotos                              # banc photo des gestes (client, écran requis)
LIBGL_ALWAYS_SOFTWARE=1 xvfb-run -a -s "-screen 0 1920x1080x24" ./gradlew runEcrans  # banc photo des écrans (fiche, mission, poste, barre) à 4 échelles ; captures dans run-photos/screenshots
```

## Cadence : ce qui tourne, et quand (pour le banc de charge)
Par PNJ, dans `Travailleur.customServerAiStep()` :
- à chaque tick : `super.customServerAiStep()` (navigation Minecraft), `tickCorps()`, l'action en cours (`Actions.Action.tick`) ;
- toutes les 10 ticks : `ramasserAutour()` (dans `tickCorps`) et `Cerveau.penser()` (décalé par `getId()` pour étaler la charge) ;
- toutes les 20 ticks : `forcerChunk()`, `tickCourrier()`, `Consignes.verifierVitesse()` ;
- toutes les 100 à 200 ticks, s'il est oisif : `Causeries.essayer` (depuis le cerveau ; une recherche d'ouvriers à 6 blocs seulement si la colonie n'a pas bavardé depuis 3 min) ;
- toutes les 100 ticks : `equiperArmure()` ; toutes les 200 ticks : inscription à l'effectif (`Courrier.inscrire`), recherche du lit.
Pour tout le serveur, dans `ColoniePnj` (`ServerTickEvent.Post`) :
- à chaque tick : `Voix.tick()` ;
- toutes les 20 ticks : `Courrier.tick()` (corbeaux arrivés) ;
- toutes les 100 ticks : `tous()` puis `forcerChunk()` pour chaque PNJ (filet de sécurité) ;
- arrivée des chercheurs d'emploi (`arriveeChercheurs`) : un compteur à chaque seconde ; toutes les 15 minutes de jour, par joueur, une recherche de cloche (`village`) et un coup d'œil aux panneaux près de son poste (`affiche`).
En arrière-plan, hors du fil du serveur : tous les appels d'IA (`IA`).
Suspects pour la charge : `tous()` parcourt toutes les entités de tous les mondes ; `Monde.chercherBloc` et `solNaturel` balaient des volumes ; le calcul des chemins dans `Itineraire` (bridé depuis la 0.8.4 : 4 recherches d'étape par tick et par PNJ, 16 pour le serveur, 20 ticks de pause après un échec complet) ; 9 chunks forcés par PNJ.

## Pièges communs
- Un PNJ seul se fige au bord d'un chunk : il faut 3 x 3 chunks forcés (`forcerChunk`).
- `Level.getHeight` sur un chunk non chargé renvoie le fond du monde : charger le chunk d'abord.
- Ne pas multiplier la vitesse en sprint (l'attribut fait déjà +30 %).
- Règles du serveur codées dans `Consignes`, `Monde.construit` et `Guerrier` : ne frapper que les monstres, ne casser que le naturel, pas de téléportation, sauf le retour au poste en dernier recours (`Travailleur.ramenerAuPoste`, codé au lot 1).
- Un bloc `static {}` qui lit des champs doit venir après eux.

## Restes de relecture du lot 1 (12/10, après la 0.8.5)
- `Monde.ligneDeTir(t, cible)` : aucun joueur, ouvrier, villageois ni bête (tout vivant non hostile) sur le segment œil → cible (boîte gonflée de 0,4) : sinon l'archer ne tire pas (`Actions.Attaquer`).
- `Actions.Attaquer` (lot 4) : avec un arc ou une arbalète et des flèches (`Guerrier.peutTirer`, revu chaque seconde), il tire de 3 à 24 blocs si la cible est hors de portée de mêlée et la ligne libre ; trop près (3 blocs, 7 pour un creeper, jamais frappé au corps à corps s'il a un arc), il recule ; sinon l'épée. `tenir(poste, laisse)` : il ne s'écarte pas du poste (consigne `garder_ici`, `Consignes.TENIR` = 6 blocs).
- `Cerveau.decider` (cahier 14.11) : un ouvrier non combattant avec un creeper en vue à 5 blocs s'en éloigne (`Fuir` vers un point trouvé d'avance, sinon il reste) et note `memoire.alerte` / `alerte_t`, que le guerrier entend.
- `Consignes` : `garder_ici` (« tiens cette porte / ce pont ») : devant une porte ou un portillon, il se poste du côté du chef ; un monstre à plus de 6 blocs de sa place n'est que guetté (tiré à l'arc s'il peut), sauf un tireur (`RangedAttackMob`) ou celui qui vient de le blesser, poursuivi jusqu'à 16 blocs (`TENIR_TIREUR`) ; `ronde_point` et `ronde_effacer` (combat, joués tout de suite dans `ordonner`).
- `Monde.combattable(e)` : sans ordre, un PNJ ne riposte que contre un monstre (`hostile`) ou un autre PNJ ; frappé par une bête, un golem ou un joueur, il recule (`Cerveau.decider`, `Monde.cibles`, `Consignes.Faire.menace`). Le bloc « attaqué » passe avant la grève.
- `Monde.mortel(l, p)` : lave, feu ou vide (chute de plus de 20 blocs) : « va là » refusé (cahier 8.5, `Consignes.ordonner`, cas `aller`).
- `Travailleur.menace()` (à terre, frappé, combat, fuite) et `enDanger()` (menace, ou monstre à 8 blocs en vue ou qui le vise) ; `lettresAuCalme` : lettres reçues en danger, lues au calme (`tickCourrier`), ou après 60 s sans menace (`auCalmeDepuis`) ; sauvegardées avec `LettresALire`, comptées dans « à lire » au poste.
- `Consignes.MESSAGE_MAX` (2 min, puis il renonce, résultat `trop_long`) et `HELER_MAX` (7 s de hélage, l'autre figé 8 s au plus) ; la limite ne joue plus une fois le message commencé.
- `Corbeau.actifSur` : tous les tronçons traversés par le trajet d'arrivée sont vérifiés (avant : un point tous les 4 blocs).
- `Itineraire.suivreSortie` : pas tout droit seulement au bout d'un chemin complet (`canReach`), sinon le point suivant de la route ; pas de recalcul en l'air, et une recherche vide ne jette pas le chemin en cours ; `commencerCreusage` : pas de marche au-dessus d'une chute de plus de 3 blocs, ni de lave ou de magma. `jeton` n'est plus privé (test `TestsCharge.jetonPourLAffame`).
